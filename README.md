# html-in-PPT 试验品

用 [html-in-PPT](https://github.com/Silhouette-my/html-in-PPT) 的 `html-deck` skill 生成的 9 页中文课堂报告，用于给作者提供实测反馈。

- **题目**：小篆不是一天写成的——秦“书同文”之前，汉字已经走了两千年
- **作者**：严毓焕（中国人民大学）
- **时长**：8 分钟

## 怎么看

- `presentation.html`：下载后双击，点右上角「演示」。第 5 页可切换「日 / 山」与甲骨 / 金文 / 小篆 / 楷书。
- `presentation.pptx`：每页一张 1600×900 截图，首页有指向同目录 HTML 的超链接。
- `slides/`：逐页截图。

在线预览 HTML（第三方渲染服务）：

https://htmlpreview.github.io/?https://raw.githubusercontent.com/Ivan666jjj/html-in-ppt-demo/main/presentation.html

## 说明

- 字形为依常见摹本简化的示意，**不是拓本**，只用于说明演变方向。
- 参考文献只列书名与出版社，版次与页码待补。
- 导出结果：`validation: passed`，9 页，PPTX 首页超链接指向 `presentation.html`。
